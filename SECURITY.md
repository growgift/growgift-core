# Security Policy

GrowGift handles payments, identity checks and investment gifts, so we take security reports seriously.

## Reporting a vulnerability

Please **do not open a public GitHub issue** for a security problem.

Email **<security contact address: to be set by the founder>** with:

- what you found and where (URL, endpoint, or file);
- steps to reproduce, and the impact you believe it has;
- your contact details if you want a reply.

We aim to acknowledge a report within 3 working days and to keep you informed until it is fixed. Please give us reasonable time to fix an issue before sharing it.

## Please do not

- access, change or delete data that is not yours;
- run tests that could degrade the service or place real payments or market orders;
- include real customer data, keys or tokens in a report.

## If you find a leaked secret

Report it the same way and, if it is a key you control, rotate it straight away.

## Supported versions

Only the current `main` branch (production) and the `staging` and `develop` branches receive fixes.

See `docs/SECURITY-AND-COMPLIANCE.md` for the controls that are in place and the known gaps.
